# Code of Conduct

## Our pledge

Be respectful. Assume good intent. No harassment, hate, or personal attacks.

## Scope

Applies to project spaces (issues, PRs, discussions) and representation of the project.

## Enforcement

Report abuse via GitHub private security advisory or maintainer contact on [0xNyk/devgod](https://github.com/0xNyk/devgod). Maintainers may warn, moderate, or ban.
