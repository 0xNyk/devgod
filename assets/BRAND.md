# devgod brand kit

Same family as [silo](https://github.com/0xNyk/silo): monochrome dark, monospace, SVG-first.

## Positioning

**One-liner:** Fullstack agent OS for TypeScript, Rust, Next.js, and Supabase.

**Tone:** Precise engineering tool. Router, gates, modules - not mystical "AI god," not neon SaaS gradients.

## Name

- Always lowercase: **devgod**
- Verb form: `devgod plan`, `devgod ship`
- Slash form: `/devgod-plan`, `/devgod-ship`

## Color (shared with silo)

| Token | Hex | Use |
|---|---|---|
| `bg` | `#0a0a0a` | Canvas, headers |
| `surface` | `#141414` / `#0f0f0f` | Cards |
| `border` | `#262626` / `#404040` | Edges |
| `text` | `#fafafa` | Primary |
| `muted` | `#a3a3a3` / `#737373` | Secondary |
| `dim` | `#525252` | Labels, meta |

No accent color. White stroke on near-black is the brand.

## Typography

- **ui-monospace / SF Mono / Menlo** only
- Wordmark: mono, weight 600, slight negative tracking

## Mark

Router tree: one root bar → three module columns → base rail. Same stroke weight language as silo's vessels (thick white stroke, rounded rects).

## Do / don't

**Do**
- Pure dark `#0a0a0a`
- Thick white geometry, gray hierarchy
- Exact text in SVG
- Match silo README shape: `![name](assets/header.svg)` → `# name` → badges → install

**Don't**
- Cyan/indigo/violet neon
- AI-generated heroes as primary brand
- Title Case DEVGOD
- Centered marketing chrome around the logo
